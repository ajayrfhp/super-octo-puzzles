# Probability Theory: Key Definitions

## Expectation (Expected Value)

- The expectation of a random variable ( X ), denoted ( mathbb{E}[X] ), is the weighted average of all possible values of ( X ) with weights given by their probabilities.

- **Discrete case:**
  [
  mathbb{E}[X] = sum_{i} x_i P(X = x_i)
  ]

- **Continuous case:**
  [
  mathbb{E}[X] = int_{-infty}^infty x f_X(x) dx
  ]
  where ( f_X(x) ) is the probability density function of ( X ).

- Intuitively, expectation represents the mean or the "center" of the distribution.

## Variance

- Variance measures the spread or dispersion of a random variable around its expectation.

- Defined as:
  [
  mathrm{Var}(X) = mathbb{E}[(X - mathbb{E}[X])^2]
  ]

- Can also be computed as:
  [
  mathrm{Var}(X) = mathbb{E}[X^2] - (mathbb{E}[X])^2
  ]

- A higher variance indicates greater spread from the mean.

## Expectation of Product of Independent Random Variables

- If ( X ) and ( Y ) are independent random variables, then:

  [
  mathbb{E}[XY] = mathbb{E}[X] cdot mathbb{E}[Y]
  ]

- This holds for both discrete and continuous variables.

- The proof relies on independence which allows the joint probability to factorize:
