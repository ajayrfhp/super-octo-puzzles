# High-Dimensional Geometry & Probability Notes

## 1. Fundamental Probability Definitions

### **Expectation ($E$)**
The expected value (or mean) is the long-run average value of repetitions of the experiment.
* **Discrete:** $E[X] = \sum x_i P(X=x_i)$
* **Continuous:** $E[X] = \int_{-\infty}^{\infty} x f(x) dx$
* **Linearity of Expectation:**
    $$E[aX + bY] = aE[X] + bE[Y]$$
    *(Note: This holds even if $X$ and $Y$ are dependent.)*

### **Variance ($V$ or $Var$)**
Variance measures how far a set of numbers is spread out from their average value.
* **Definition:** $V[X] = E[(X - E[X])^2]$
* **Computational Formula:**
    $$V[X] = E[X^2] - (E[X])^2$$
* **Properties:**
    * $V[aX + b] = a^2 V[X]$
    * If $X$ and $Y$ are **independent**: $V[X + Y] = V[X] + V[Y]$

## 2. Product Moments ($XY$)

### **Expectation of a Product: $E[XY]$**
* **General Case:** $E[XY] = E[X]E[Y] + \text{Cov}(X, Y)$
* **If $X, Y$ are Independent:** $\text{Cov}(X, Y) = 0$, so:
    $$E[XY] = E[X]E[Y]$$

### **Variance of a Product: $V[XY]$**
This is often derived using the formula $V[Z] = E[Z^2] - (E[Z])^2$.
Assuming $X$ and $Y$ are **independent**:
1.  $E[XY] = E[X]E[Y]$
2.  $E[(XY)^2] = E[X^2 Y^2] = E[X^2]E[Y^2]$
3.  **Formula:**
    $$V[XY] = E[X^2]E[Y^2] - (E[X])^2(E[Y])^2$$
    *Alternatively expressed using variances:*
    $$V[XY] = V[X]V[Y] + V[X](E[Y])^2 + V[Y](E[X])^2$$

## 3. The Dimensionality Exercise (Code)

This script visualizes the **Concentration of Measure**. It shows that as dimension $d$ increases, the probability mass of a random vector's length concentrates tightly around $\sqrt{d}$.

```python
import matplotlib.pyplot as plt
import numpy as np
from scipy.stats import chi

# 1. Define Dimensions
# We compare low dimensions (3) vs high dimensions (100)
dims = [3, 20, 100]

# 2. Set up the X-axis (Distance from Origin / Radius)
x = np.linspace(0, 15, 500)

plt.figure(figsize=(10, 6))

# 3. Plot Distribution for each Dimension
# The length of a vector with d standard normal coordinates follows 
# a Chi distribution (square root of Chi-Squared).
for d in dims:
    y = chi.pdf(x, df=d)
    plt.plot(x, y, label=f'Dimension d={d}', linewidth=2)

# 4. Formatting
plt.title('Distribution of Distance from Origin for Random Vectors')
plt.xlabel('Distance from Origin (Length)')
plt.ylabel('Probability Density')
plt.legend()
plt.grid(True, alpha=0.3)

# 5. Highlight the expected length for d=100
# Expected length is approx sqrt(d) -> sqrt(100) = 10
plt.axvline(np.sqrt(100), color='red', linestyle='--', alpha=0.5)
plt.text(np.sqrt(100), 0.1, ' $\sqrt{100}=10$', color='red', rotation=90)

# plt.savefig('concentration_of_measure.png')
plt.show()
```

## 5. Derivations & Proofs

### A. Proof: Linearity of Expectation
**Goal:** Show that $E[aX + bY] = aE[X] + bE[Y]$.

**Proof (Continuous Case):**
By definition, the expectation of a function $g(x,y)$ over a joint probability density $f(x,y)$ is:
$$E[g(X,Y)] = \iint g(x,y) f(x,y) \,dx\,dy$$

1.  **Substitute** $g(x,y) = ax + by$:
    $$E[aX + bY] = \iint (ax + by) f(x,y) \,dx\,dy$$
2.  **Distribute** the density function $f(x,y)$:
    $$= \iint (ax f(x,y) + by f(x,y)) \,dx\,dy$$
3.  **Split the integrals** (property of integration):
    $$= \iint ax f(x,y) \,dx\,dy + \iint by f(x,y) \,dx\,dy$$
4.  **Factor out constants** ($a$ and $b$):
    $$= a \iint x f(x,y) \,dx\,dy + b \iint y f(x,y) \,dx\,dy$$
5.  **Identify the Marginal Expectations:**
    Since $\int x f(x,y) \,dx\,dy = E[X]$, we get:
    $$= aE[X] + bE[Y]$$
    *(Note: The logic is identical for discrete sums.)*

---

### B. Proof: The Variance "Shortcut" Formula
**Goal:** Show that $V[X] = E[X^2] - (E[X])^2$.

**Proof:**
We start with the definition of variance, where $\mu = E[X]$.
$$V[X] = E[(X - \mu)^2]$$

1.  **Expand the quadratic term:**
    $$(X - \mu)^2 = X^2 - 2\mu X + \mu^2$$
2.  **Apply Linearity of Expectation:**
    $$E[X^2 - 2\mu X + \mu^2] = E[X^2] - E[2\mu X] + E[\mu^2]$$
3.  **Simplify terms:**
    * $E[X^2]$ remains the same.
    * Since $2\mu$ is a constant, $E[2\mu X] = 2\mu E[X]$.
    * Since $\mu^2$ is a constant, $E[\mu^2] = \mu^2$.
4.  **Substitute** $E[X] = \mu$:
    $$= E[X^2] - 2\mu(\mu) + \mu^2$$
    $$= E[X^2] - 2\mu^2 + \mu^2$$
    $$= E[X^2] - \mu^2$$
5.  **Final Result:**
    $$V[X] = E[X^2] - (E[X])^2$$

---

### C. Proof: Variance of a Product (Independent Variables)
**Goal:** Show that $V[XY] = E[X^2]E[Y^2] - (E[X])^2(E[Y])^2$ given $X, Y$ are independent.

**Proof:**
We use the variance shortcut formula on the variable $Z = XY$.
$$V[XY] = E[(XY)^2] - (E[XY])^2$$

1.  **Analyze the first term** $E[(XY)^2]$:
    $$E[(XY)^2] = E[X^2 Y^2]$$
    Because $X$ and $Y$ are independent, $X^2$ and $Y^2$ are also independent. Therefore:
    $$E[X^2 Y^2] = E[X^2]E[Y^2]$$
2.  **Analyze the second term** $(E[XY])^2$:
    Because $X$ and $Y$ are independent:
    $$E[XY] = E[X]E[Y]$$
    Squaring this gives:
    $$(E[X]E[Y])^2 = (E[X])^2 (E[Y])^2$$
3.  **Combine them:**
    $$V[XY] = E[X^2]E[Y^2] - (E[X])^2(E[Y])^2$$
