# Puzzle Notes: The Server State (Markov Chains & Eigenvectors)

This document summarizes the solution to the Server State puzzle, highlighting the connection between steady-state probabilities and eigenvectors.

## 1. The Puzzle: Server States

**Scenario:** A server transitions between three states (`IDLE`, `BUSY`, `ERROR`) every second based on a transition matrix.

**Transition Matrix ($A$):**
(Probabilities of moving *from* Row *to* Column)

| From \ To | IDLE | BUSY | ERROR |
| :--- | :---: | :---: | :---: |
| **IDLE** | 0.5 | 0.5 | 0.0 |
| **BUSY** | 0.4 | 0.5 | 0.1 |
| **ERROR** | 1.0 | 0.0 | 0.0 |

**Goal:** Find the **steady-state probability** for each state (percentage of time spent in each state in the long run).

## 3. The Math & Intuition

### The Core Equation: $A\mathbf{v} = \mathbf{v}$
Finding the steady state is exactly the same as finding the **eigenvector** corresponding to the **eigenvalue of 1**.

If $\mathbf{v}$ is our vector of probabilities (the state of the system), and $A$ is our transition matrix, then the state at the *next* second is $A\mathbf{v}$.
If the system is in a **steady state**, the state doesn't change. Therefore:
$$A\mathbf{v} = \mathbf{v}$$

### The System of Equations
We solve this by treating it as a system of linear equations, subject to the constraint that probabilities sum to 1 ($\sum v_i = 1$).

Based on the matrix columns (flows *into* a state):
1.  **Into IDLE:** $0.5v_I + 0.4v_B + 1.0v_E = v_I$
2.  **Into BUSY:** $0.5v_I + 0.5v_B + 0.0v_E = v_B$
3.  **Into ERROR:** $0.0v_I + 0.1v_B + 0.0v_E = v_E$

### Solving
From equation (2):
$$0.5v_I = 0.5v_B \implies v_I = v_B$$

From equation (3):
$$v_E = 0.1v_B$$

Now use the normalization constraint:
$$v_I + v_B + v_E = 1$$
$$v_B + v_B + 0.1v_B = 1$$
$$2.1v_B = 1$$

$$v_B = \frac{1}{2.1} \approx 0.476$$

Since $v_I = v_B$, then $v_I \approx 0.476$.
And $v_E = 0.1(0.476) \approx 0.0476$.
