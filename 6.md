# Puzzle Notes: The Infinite Stream (Reservoir Sampling)

This document summarizes the solution to the "Infinite Stream" puzzle, a classic problem in probability and streaming algorithms.

---

## The Problem

**Scenario:** You are processing an infinite stream of data items $x_1, x_2, x_3, \dots$. You do not know the total number of items ($N$) in advance.

**Constraint:** You have limited memory and can store exactly **one** item at a time.

**Goal:** At any step $n$, the item currently stored in memory must be a **uniform random sample** of all items seen so far. This means every item $x_1 \dots x_n$ has a $\frac{1}{n}$ probability of being the selected one.

---

## The Algorithm

To maintain a uniform random sample:

1.  **Initialization ($n=1$):** Always store the first item $x_1$.
2.  **Step $n$:** When the $n$-th item ($x_n$) arrives:
    * Decide to **keep** $x_n$ with probability **$\frac{1}{n}$**.
    * If you keep $x_n$, discard the old item.
    * Otherwise, keep the old item.

### Generalization (Size $k$)
If you want to maintain a sample of size $k$ (where $k > 1$):
1.  Fill the reservoir with the first $k$ items.
2.  For the $n$-th item (where $n > k$), keep it with probability **$\frac{k}{n}$**.
3.  If kept, replace one of the existing $k$ items chosen uniformly at random.

---

## The Proof (Mathematical Induction)

We want to prove that for any item $x_i$ (where $i \le n$), the probability it is in the reservoir ($R_n$) is exactly $\frac{1}{n}$.

### 1. Base Case ($n=1$)
When the first item arrives, we store it with probability 1.
$$P(R_1 = x_1) = \frac{1}{1} = 1$$
The base case holds.

### 2. Inductive Step
**Assumption:** Assume the rule holds for step $n-1$. That is, for any item $x_i$ seen so far, the probability it is in the reservoir is $\frac{1}{n-1}$.

Now, item $x_n$ arrives. We keep it with probability $P(K) = \frac{1}{n}$.
The probability we *don't* swap is $P(K^c) = 1 - \frac{1}{n} = \frac{n-1}{n}$.

**Case A: The New Item ($x_n$)**
For $x_n$ to be the sample, we just have to decide to keep it.
$$P(R_n = x_n) = \frac{1}{n}$$
(Correct)

**Case B: An Old Item ($x_i$, where $i < n$)**
For an old item to be the sample, two things must happen:
1.  It was already in the reservoir ($R_{n-1} = x_i$).
2.  We decided **not** to swap it for the new item ($K^c$).

$$P(R_n = x_i) = P(R_{n-1} = x_i) \times P(K^c)$$

Substitute our Assumption ($\frac{1}{n-1}$) and the swap probability ($\frac{n-1}{n}$):

$$P(R_n = x_i) = \frac{1}{n-1} \times \frac{n-1}{n}$$

The $(n-1)$ terms cancel out:

$$P(R_n = x_i) = \frac{1}{n}$$
(Correct)

---

## Why This Matters (ML & Core CS)

* **Big Data:** This is crucial when the dataset is too large to fit in memory (e.g., huge log files).
* **Streaming:** It allows you to generate representative training batches from a live data stream in real-time.
* **Efficiency:** It requires only $O(1)$ (constant) memory and a single pass over the data.
