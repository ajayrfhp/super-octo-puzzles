# Puzzle Notes: Backpropagation in a Single Sigmoid Neuron

This document outlines the step-by-step derivation of the gradient for a simple neural network, which forms the basis of backpropagation.

---

## 1. The Problem Setup

We have a single-neuron network with one input $x$, one weight $w$, and one true label $y$.

### The Forward Pass

The calculation proceeds in three steps:

1.  **Linear Step:** The input is multiplied by the weight.
    $$z = w \cdot x$$

2.  **Activation:** The result is passed through a sigmoid activation function ($\sigma$).
    $$a = \sigma(z) = \frac{1}{1 + e^{-z}}$$

3.  **Loss:** The output $a$ is compared to the true label $y$ using a squared error loss function $L$.
    $$L = \frac{1}{2}(a - y)^2$$

### The Goal

Our objective is to find the gradient of the Loss with respect to the weight, $\frac{\partial L}{\partial w}$. This tells us how a small change in $w$ will affect the final Loss, allowing us to "learn" by updating the weight.

---

## 2. The Solution: The Chain Rule

We cannot compute $\frac{\partial L}{\partial w}$ directly. We must use the **chain rule** to propagate the gradient backward from the loss.

The chain rule breaks the problem down into a product of simpler derivatives:

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}$$

We can solve each of these three parts individually.
